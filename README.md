# GCam Boost

## Description
An LSPosed module that lets you use some newer Pixel exclusive GCam features on some older Pixels. Also brings back the legendary Photo Sphere!

Tested on Pixel 8 Pro with GCam [10.3.183.888945295.14](https://www.apkmirror.com/apk/google-inc/camera/pixel-camera-10-3-183-888945295-14-release/pixel-camera-10-3-183-888945295-14-android-apk-download/).

⚠️ Video Boost cloud processing won't work if you use Unlimited Storage (Pixel XL spoof).

## Supported devices
* Pixel 8 Pro
* Pixel 9 Pro series
* Pixel 10 Pro series (for now the only benefit is **Photo Sphere**)

### Older Pixel devices
Some features like Camera Coach or Photo Sphere should work on any Pixel device. 

## Installation
1. Install the APK.
2. Enable the **GCam Boost** module in **LSPosed Manager**.
3. Ensure **Pixel Camera** (`com.google.android.GoogleCamera`) is selected in the module's scope.
4. Restart **Pixel Camera**.
