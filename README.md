# GCam Boost

## Description
An LSPosed module that lets you use some newer Pixel exclusive GCam features on some older Pixels. Also brings back the legendary Photo Sphere!

Tested on Pixel 8 Pro with GCam [11.0.073.961838058.30](https://www.apkmirror.com/apk/google-inc/camera/pixel-camera-11-0-073-961838058-30-release/pixel-camera-11-0-073-961838058-30-android-apk-download/).

⚠️ Video Boost cloud processing won't work if you use Unlimited Storage (Pixel XL spoof).

## Supported devices
* Pixel 8 Pro
* Pixel 9 Pro series
* Pixel 10 Pro series 
* Pixel 11 Pro series (for now the only benefit is **Photo Sphere**)

### Other Pixel Devices
Some features like **Camera Coach** or **Quick Access Controls** should work on any Pixel device. 

## Installation
1. Install the APK.
2. Enable the **GCam Boost** module in **LSPosed Manager**.
3. Ensure **Pixel Camera** (`com.google.android.GoogleCamera`) is selected in the module's scope.
4. Restart **Pixel Camera**.
